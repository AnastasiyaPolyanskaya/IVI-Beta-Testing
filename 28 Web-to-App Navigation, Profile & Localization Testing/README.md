# 28  Web-to-App Navigation, Profile & Localization Testing

Практический проект по ручному тестированию мобильного приложения **IVI** для iOS после обновления механизмов перехода из веб-версии, интерфейса профиля, раздела «Покупки» и системы локализации.

В рамках проекта проведена проверка стабильности работы приложения, корректности навигации, отображения пользовательского интерфейса и текстовых ресурсов после внесённых изменений.

---

## Цель проекта

Проверить корректность работы обновлённого функционала приложения, убедиться в отсутствии регрессий и выявить возможные дефекты пользовательского интерфейса и логики работы.

---

## Объект тестирования

Мобильное приложение **IVI**

- Платформа: iOS
- Тип тестирования: Manual QA
- Устройство: iPhone 14 Pro Max

---

## Области тестирования

### 1. Переход из веб-версии в приложение

Проверено:

- открытие карточки контента по диплинку;
- переход из мобильной веб-версии;
- отсутствие зависаний (фризов) после открытия приложения.

---

### 2. Экран оценки приложения

Проверено:

- отображение экрана оценки приложения после просмотра контента;
- корректность появления поп-апа после выполнения необходимых условий.

---

### 3. Экран профиля

Проверено:

- расположение кнопки «Настройки»;
- расположение кнопки «О сервисе»;
- расположение кнопки «Поддержка»;
- переходы между разделами;
- возврат в профиль с помощью кнопки «Назад», свайпа и навигационной панели.

---

### 4. Раздел «Покупки»

Проверено:

- открытие раздела;
- навигация внутри раздела;
- отображение приобретённого контента;
- корректность входа и выхода из раздела.

---

### 5. Локализация интерфейса

Проверено:

- отображение текстов пользовательского интерфейса;
- отсутствие технических ключей локализации;
- отсутствие обрезанного текста;
- корректность переносов строк;
- соответствие текстов контексту отображаемого экрана.

---

## Особенности тестирования

Тестирование проводилось с учётом:

- переходов между веб-версией и приложением;
- различных пользовательских сценариев авторизации;
- проверки навигации между экранами;
- проверки пользовательского интерфейса;
- проверки локализации приложения.

---

## Результаты тестирования

В ходе тестирования проверены:

- переход из веб-версии в приложение;
- отображение экрана оценки приложения;
- обновлённый экран профиля;
- раздел «Покупки»;
- локализация пользовательского интерфейса.

Все выявленные несоответствия оформлены в отдельных баг-репортах.

---

## Структура проекта

В репозитории представлены:

- **test-cases** — тест-кейсы;
- **bug-reports** — баг-репорты;
- **screenshots** — скриншоты, подтверждающие результаты тестирования.
