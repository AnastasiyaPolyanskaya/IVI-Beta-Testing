# Bug Reports - IVI iOS Project 28 (Web-to-App Navigation, Profile & Localization)

В данном разделе представлены баг-репорты, составленные по результатам ручного тестирования мобильного приложения **IVI** после обновления навигации между веб-версией и приложением, экрана профиля, раздела «Покупки» и системы локализации.

Все дефекты оформлены на основании выполненных тест-кейсов и содержат подробное описание условий воспроизведения, ожидаемого и фактического результата.

---

## Цель

Зафиксировать обнаруженные дефекты, определить их влияние на пользовательский опыт и предоставить разработчикам информацию, необходимую для их устранения.

---

## Объект тестирования

Мобильное приложение **IVI**

- Платформа: iOS
- Тип тестирования: Manual QA
- Устройство: iPhone 14 Pro Max

---

## Области выявленных дефектов

### 1. Переход из веб-версии в приложение

Проверено:

- открытие карточки контента по диплинку;
- отсутствие зависаний при переходе.

**Выявленный дефект:**

- после перехода из веб-версии приложение сначала отображает последний открытый экран (например, главную страницу), который остается неактивным около **4–5 секунд**, и только затем происходит переход на карточку контента. Формально зависания нет, однако пользователь наблюдает заметную задержку перед открытием нужного экрана.

---

### 2. Локализация интерфейса

Проверено:

- отображение текстов на различных языках;
- корректность локализации элементов интерфейса.

**Выявленный дефект:**

- часть экранов и элементов интерфейса остается на исходном языке, тогда как остальные разделы уже переведены. Наблюдается неполная локализация пользовательского интерфейса.

---

## Проверенные сценарии без замечаний

Во время тестирования следующие функции соответствовали ожидаемому результату:

- отображение экрана оценки приложения после просмотра контента (IOS-20167);
- обновленный экран профиля и расположение кнопок (IOS-20000);
- работа раздела «Покупки» после перехода на новый внутренний сервис (IOS-19226).

> **Примечание:** функциональность раздела «Покупки» проверена частично, поскольку на тестовом аккаунте присутствовало только два приобретённых фильма.

## Используемая классификация

### Severity

- **Critical** — приложение невозможно использовать;
- **Major** — нарушен основной пользовательский сценарий;
- **Minor** — функциональность работает частично либо имеются заметные проблемы интерфейса;
- **Trivial** — косметические дефекты.

### Priority

- **High** — требуется исправление в ближайшем релизе;
- **Medium** — рекомендуется исправить в одном из следующих релизов;
- **Low** — исправление может быть отложено.

---

## Вывод

По результатам тестирования большинство сценариев выполнено успешно и соответствует ожидаемому результату. Вместе с тем были выявлены отдельные проблемы, связанные с задержкой открытия карточки контента при переходе из веб-версии приложения и неполной локализацией пользовательского интерфейса. Данные дефекты не блокируют использование приложения, однако оказывают влияние на удобство работы пользователей и требуют исправления в последующих версиях.
