# Test Cases  (Web-to-App Navigation, Profile & Localization)

В данном разделе представлены тест-кейсы, разработанные для проверки обновлённого функционала мобильного приложения **IVI** после внесённых изменений в навигацию, экран профиля, раздел «Покупки» и систему локализации.

Тест-кейсы охватывают основные пользовательские сценарии и позволяют проверить корректность работы приложения после обновления.

---

## Цель

Проверить стабильность работы приложения, корректность навигации, отображения пользовательского интерфейса и локализованных текстов, а также убедиться в отсутствии регрессий после внесённых изменений.

---

## Объект тестирования

Мобильное приложение **IVI**

- Платформа: iOS
- Тип тестирования: Manual QA
- Устройство: iPhone 14 Pro Max

---

## Области тестирования

### 1. Переход из веб-версии

Проверено:

- открытие карточки контента через веб;
- переход по кнопке «Открыть в приложении»;
- отсутствие зависаний (фризов) при переходе.

---

### 2. Экран оценки приложения

Проверено:

- отображение экрана оценки после просмотра контента;
- выполнение условий появления окна оценки;
- корректность отображения интерфейса.

---

### 3. Экран профиля

Проверено:

- расположение кнопки «Настройки»;
- расположение кнопки «О сервисе»;
- расположение кнопки «Поддержка»;
- переходы между разделами;
- возврат в профиль с помощью кнопки «Назад», свайпа и навигационной панели.

---

### 4. Раздел «Покупки»

Проверено:

- открытие раздела;
- корректность навигации;
- отображение приобретённого контента;
- вход и выход из раздела.

---

### 5. Локализация интерфейса

Проверено:

- корректность отображения текстов;
- отсутствие технических ключей локализации;
- отсутствие обрезанного текста;
- корректность переносов строк;
- соответствие текста элементам интерфейса.

---

## Особенности тестирования

Тестирование выполнялось с использованием ручного тестирования (Manual QA) и включало проверку:

- пользовательских сценариев навигации;
- взаимодействия между веб-версией и мобильным приложением;
- элементов пользовательского интерфейса;
- отображения локализованных текстов;
- стабильности работы приложения после обновления.

---

## Результат выполнения

По итогам выполнения тест-кейсов были определены сценарии, соответствующие ожидаемому результату, а также выявлены дефекты, оформленные в отдельных баг-репортах.
