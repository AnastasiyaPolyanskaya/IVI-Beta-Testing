# Bug Reports  (Downloads, Web Profile & Continue Watching)

В данном разделе представлены баг-репорты, составленные по результатам тестирования мобильного приложения **IVI** после обновления функциональности загрузок, web-профиля пользователя и блока **«Продолжить просмотр»**.

В процессе тестирования проверялись пользовательские сценарии, связанные с удалением загрузок, отображением web-профиля, работой раздела «Покупки», локализацией интерфейса и переходами между экранами.

---

## Цель

Зафиксировать обнаруженные дефекты, описать условия их воспроизведения и предоставить информацию, необходимую для их дальнейшего анализа и исправления.

---

## Области дефектов

В ходе тестирования были выявлены дефекты в следующих функциональных областях:

### 1. Переходы между вебом и приложением

Проверено:

- открытие карточки контента из веб-версии;
- отсутствие зависаний при переходе в приложение.

**Выявленная особенность:**

- при открытии карточки контента приложение сначала отображает предыдущий экран (например, главную страницу), после чего через 4–5 секунд выполняется переход на нужную карточку контента. В течение этого времени интерфейс не реагирует на действия пользователя.

---

### 2. Локализация интерфейса

Выявлено:

- отдельные разделы интерфейса не переведены на выбранный язык;
- часть экранов отображается на другом языке, несмотря на корректную локализацию остальных элементов приложения.

---

## Структура баг-репорта

Каждый баг-репорт содержит:

- ID;
- Название;
- Окружение;
- Предусловия;
- Шаги воспроизведения;
- Ожидаемый результат;
- Фактический результат;
- Severity (Серьёзность);
- Priority (Приоритет);
- Комментарий.

---

## Окружение

Тестирование проводилось на:

- **iPhone 14 Pro Max**
- **iOS 26.6.x**
- **Приложение IVI (TestFlight)**

---

## Серьёзность дефектов

В проекте использовалась следующая классификация:

- **Critical** — приложение невозможно использовать;
- **Major** — нарушен основной пользовательский сценарий;
- **Minor** — функциональность работает частично или имеются отдельные недостатки;
- **Trivial** — незначительные визуальные или косметические дефекты.

---

## Итоги тестирования

Большинство проверяемых сценариев завершились успешно:

- удаление активной загрузки работает корректно;
- экран оценки приложения отображается;
- обновлённый профиль функционирует корректно;
- раздел «Покупки» работает без ошибок в проверенных сценариях.

При этом были обнаружены следующие проблемы:

- задержка при переходе из веб-версии приложения на карточку контента;
- неполная локализация отдельных разделов пользовательского интерфейса.

Данные дефекты требуют дополнительной проверки и исправления для обеспечения стабильной работы приложения и единообразного отображения интерфейса на всех поддерживаемых языках.
