# 33 - TV Channels, Favorites Sync, Search Filters & Email Authorization

Практический проект по исследовательскому, функциональному и UI/UX-тестированию сервиса IVI.  
Ниже представлен чек-лист проверки свежих исправлений в iOS-приложении.

## Структура проверок

### Страница «ТВ-каналы»

**Что проверить:**
1. Открыть Поиск → вкладка «Каталог» → «ТВ-каналы» (или Поиск → «ТВ»)
2. В галерее категорий ТВ-каналов нажать на заголовок категории (например, «Развлекательные»)
3. На открывшейся странице переключить вкладку категории вверху

**Ожидаемый результат IOS-19979.1:**  
Открывается отдельная страница со списком ТВ-каналов выбранной категории. В верхней части экрана отображаются вкладки категорий, выбранная категория активна. При переключении вкладки список каналов изменяется в соответствии с выбранной категорией.

---

### Список ТВ-каналов на отдельной странице

**Что проверить:**
1. Открыть отдельную страницу со списком ТВ-каналов
2. Проскроллить список каналов вниз до подгрузки новых
3. Проверить карточку канала: постер, название, текущую передачу и полоску прогресса
4. Нажать на канал
5. Вернуться назад с помощью кнопки или свайпа

**Ожидаемый результат IOS-19979.2:**  
Новые каналы подгружаются корректно и без дубликатов. На карточках отображается полоса прогресса текущей передачи. Переход в карточку канала и возврат назад работают корректно, позиция скролла после возврата сохраняется.

---

### Добавление в «Избранное»

**Что проверить:**
1. Открыть карточку любого фильма или сериала
2. Нажать «Буду смотреть»
3. Проверить добавление контента в «Избранное»
4. Повторно нажать «Буду смотреть» и проверить удаление
5. Перейти на Главную
6. Нажать и удерживать постер контента
7. В открывшемся меню выбрать «Буду смотреть»
8. Повторить действие и удалить контент из «Избранного»

**Ожидаемый результат IOS-17724.1:**  
Контент корректно добавляется и удаляется из «Избранного» как из карточки контента, так и через меню постера на Главной. Состояние кнопки «Буду смотреть» соответствует текущему состоянию контента.

---

### Сквозная синхронизация «Избранного»

**Что проверить:**
1. Добавить сериал в «Буду смотреть» из карточки контента
2. Вернуться на Главную
3. Найти этот сериал в ленте
4. Проверить состояние «Буду смотреть»
5. Запустить любой контент в плеере
6. Выйти из плеера
7. Снова открыть карточку сериала, добавленного в «Буду смотреть»

**Ожидаемый результат IOS-17724.2:**  
Состояние «Буду смотреть» синхронизировано на всех экранах приложения: в карточке контента, ленте Главной и плеере. Для обновления состояния не требуется перезапуск приложения.

---

### Фильтры на экране Поиска

**Что проверить:**
1. Открыть Поиск
2. Нажать кнопку фильтров
3. Проверить верхнюю часть экрана «Фильтры»
4. Убедиться в наличии вкладок «Все», «Сериалы», «Фильмы», «Мультфильмы»
5. Выбрать несколько фильтров
6. Переключить вкладку категории, например на «Сериалы»
7. Проверить сброс ранее выбранных фильтров
8. Нажать «Показать»

**Ожидаемый результат IOS-20622:**  
На экране «Фильтры» отображаются вкладки категорий «Все», «Сериалы», «Фильмы» и «Мультфильмы». При переключении категории ранее выбранные фильтры сбрасываются. После нажатия «Показать» открываются результаты, соответствующие выбранной категории.

---

### Ввод email при авторизации

**Предусловие:**  
- Пользователь не авторизован в приложении

**Что проверить:**
1. Выйти из аккаунта
2. Начать авторизацию по email
3. Нажать на поле ввода email
4. Начать вводить адрес электронной почты
5. Проверить регистр первой введённой буквы
6. Проверить правую часть поля ввода на наличие визуальных артефактов

**Ожидаемый результат IOS-20649:**  
Первая буква email не переводится автоматически в верхний регистр. В правой части поля ввода отсутствуют лишние красные элементы и другие визуальные артефакты.
