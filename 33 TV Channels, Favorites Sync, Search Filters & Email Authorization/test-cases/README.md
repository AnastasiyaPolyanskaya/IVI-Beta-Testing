# Test Cases TV Channels, Favorites, Search Filters & Email Authorization

В данном разделе представлены тест-кейсы, разработанные для проверки функциональности мобильного приложения **IVI** после обновлений и исправлений, связанных с ТВ-каналами, добавлением контента в «Избранное», синхронизацией состояния «Буду смотреть», фильтрами поиска и авторизацией по email.

Тест-кейсы охватывают основные пользовательские сценарии и позволяют проверить корректность работы обновлённого функционала, а также убедиться в отсутствии регрессионных ошибок.

---

## Цель

Проверить корректность работы новой и исправленной функциональности и подтвердить соответствие поведения приложения ожидаемым требованиям после внесённых изменений.

---

## Объект тестирования

Мобильное приложение **IVI**

- Платформа: iOS
- Тип тестирования: Manual QA
- Устройство: iPhone 16 Pro

---

## Области тестирования

### 1. Страница «ТВ-каналы»

Проверены сценарии:

- открытие раздела «ТВ-каналы» через Поиск → Каталог;
- открытие раздела через вкладку «ТВ»;
- переход на отдельную страницу выбранной категории;
- отображение вкладок категорий в верхней части экрана;
- корректное отображение активной категории;
- переключение между категориями;
- обновление списка каналов после переключения категории.

Связанная задача:

- **IOS-19979.1**

---

### 2. Список ТВ-каналов

Проверены:

- отображение списка ТВ-каналов выбранной категории;
- скролл списка;
- подгрузка новых каналов;
- отсутствие дубликатов при подгрузке;
- отображение постера канала;
- отображение названия канала;
- отображение текущей передачи;
- отображение полосы прогресса;
- переход в карточку канала;
- возврат на предыдущий экран;
- сохранение позиции скролла после возврата.

Связанная задача:

- **IOS-19979.2**

---

### 3. Добавление контента в «Избранное»

Проверены сценарии:

- добавление фильма в «Буду смотреть» из карточки контента;
- добавление сериала в «Буду смотреть»;
- удаление контента повторным нажатием;
- изменение состояния кнопки после добавления;
- изменение состояния кнопки после удаления;
- добавление контента через меню постера на Главной;
- удаление контента через меню постера;
- корректное отображение состояния «Буду смотреть».

Связанная задача:

- **IOS-17724.1**

---

### 4. Сквозная синхронизация «Избранного»

Проверены:

- добавление сериала в «Буду смотреть» из карточки;
- отображение состояния добавленного контента на Главной;
- сохранение состояния после перехода между экранами;
- запуск контента в плеере;
- возврат из плеера;
- повторное открытие карточки сериала;
- синхронизация состояния «Буду смотреть» между карточкой, Главной и плеером;
- обновление состояния без перезапуска приложения.

Связанная задача:

- **IOS-17724.2**

---

### 5. Фильтры на экране Поиска

Проверены:

- открытие экрана «Фильтры»;
- отображение вкладки «Все»;
- отображение вкладки «Сериалы»;
- отображение вкладки «Фильмы»;
- отображение вкладки «Мультфильмы»;
- выбор параметров фильтрации;
- переключение между категориями;
- сброс выбранных фильтров после переключения категории;
- работа кнопки «Показать»;
- отображение результатов выбранной категории.

Связанная задача:

- **IOS-20622**

---

### 6. Ввод email при авторизации

Проверены:

- выход из авторизованного аккаунта;
- запуск авторизации по email;
- активация поля ввода email;
- ввод адреса электронной почты;
- отсутствие автоматического перевода первой буквы в верхний регистр;
- отображение правой части поля ввода;
- отсутствие лишних красных элементов;
- отсутствие визуальных артефактов в поле ввода.

Связанная задача:

- **IOS-20649**

---

## Структура тест-кейса

Каждый тест-кейс содержит:

- ID;
- Название;
- Связанную задачу;
- Предусловия;
- Шаги выполнения;
- Ожидаемый результат;
- Фактический результат;
- Приоритет;
- Окружение;
- Статус выполнения (Passed / Failed / Blocked).

---

## Окружение

Тестирование проводится на:

- **iPhone 16 Pro**
- **iOS**
- **Приложение IVI**

---

## Связанные задачи

В рамках проекта проверяются следующие задачи:

- **IOS-19979.1** — отдельная страница категории ТВ-каналов;
- **IOS-19979.2** — список ТВ-каналов, подгрузка и сохранение позиции скролла;
- **IOS-17724.1** — добавление и удаление контента из «Избранного»;
- **IOS-17724.2** — сквозная синхронизация состояния «Буду смотреть»;
- **IOS-20622** — вкладки категорий и фильтры на экране Поиска;
- **IOS-20649** — корректный ввод email при авторизации.

---

## Назначение тест-кейсов

Тест-кейсы используются для:

- проверки корректности новой и исправленной функциональности;
- проведения функционального тестирования;
- проведения регрессионного тестирования;
- UI/UX-тестирования;
- проверки навигации между экранами;
- проверки динамической подгрузки ТВ-каналов;
- проверки сохранения позиции скролла;
- тестирования добавления и удаления контента из «Избранного»;
- проверки синхронизации состояния между экранами;
- тестирования фильтрации контента;
- тестирования формы авторизации;
- проверки соответствия фактического поведения ожидаемому;
- документирования результатов тестирования;
- подготовки баг-репортов при обнаружении дефектов.
