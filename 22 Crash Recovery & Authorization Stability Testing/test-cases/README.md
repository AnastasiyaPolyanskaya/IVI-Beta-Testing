# Test Cases - IVI (Crash Recovery & Authorization Stability)

В данном разделе представлены тест-кейсы для проверки стабильности мобильного приложения IVI после исправления критических ошибок.

Тест-кейсы охватывают пользовательские сценарии, связанные со скачиванием контента и ограничением количества авторизованных устройств.

---

## Цель тестирования

Проверить отсутствие крашей приложения после внесённых исправлений и убедиться в корректной работе ключевых сценариев.

---

## Область покрытия

### 1. Скачивание контента

Проверено:

- скачивание большого количества контента;
- поведение приложения при переполненной памяти устройства;
- попытка скачать дополнительный контент после полного заполнения памяти;
- стабильность приложения при работе со скачиванием.

---

### 2. Ограничение количества устройств

Проверено:

- отображение экрана ограничения устройств;
- отключение одного устройства;
- отключение нескольких устройств;
- закрытие экрана ограничений;
- стабильность приложения при взаимодействии с экраном ограничений.

---

## Структура тест-кейсов

Каждый тест-кейс содержит:

- ID  
- Название  
- Предусловия  
- Шаги выполнения  
- Ожидаемый результат (ОР)  
- Фактический результат (ФР)  
- Окружение  
- Результат  

---

## Окружение

Тестирование проводилось на:

- iPhone 14 Pro Max  
- iOS 26.6.4  

---

## Особенности тестирования

- проверка стресс-сценариев;
- тестирование нестандартных пользовательских условий;
- проверка стабильности после исправления критических дефектов;
- тестирование ограничений авторизации устройств.
