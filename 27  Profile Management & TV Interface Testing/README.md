# 27 - Profile Management & TV Interface Testing

Данный проект посвящён ручному тестированию мобильного приложения IVI для iOS после обновления пользовательского интерфейса, системы навигации и внутренних компонентов приложения.

В рамках проекта была проведена проверка работы профилей пользователей, навигации между экранами, раздела способов оплаты, карточек коллекций и отображения телевизионных передач после внесённых изменений в приложение.

---

## Цель проекта

Проверить стабильность работы приложения после обновления, убедиться в корректной работе пользовательских сценариев и выявить возможные дефекты.

---

## Что проверялось

В ходе тестирования были проверены следующие функциональные области:

- работа приложения после восстановления интернет-соединения;
- переключение между детским и взрослым профилями;
- отсутствие отображения взрослого контента в детском профиле;
- открытие раздела «Способы оплаты»;
- оформление подписки;
- работа навигации между экранами;
- плавность анимаций интерфейса;
- открытие карточек коллекций;
- отображение изображений и превью коллекций;
- работа скролла и переходов внутри карточек;
- отображение временных шильдов на постерах ТВ-передач;
- корректность текста и цветового оформления шильдов.

---

## Структура проекта

Проект включает следующие разделы:

- **Test Cases** — тест-кейсы для проверки пользовательских сценариев;
- **Bug Reports** — баг-репорты по обнаруженным дефектам;
- **Screenshots** — скриншоты, подтверждающие результаты тестирования.

---

## Окружение

Тестирование выполнялось на следующем устройстве:

- **iPhone 14 Pro Max**
- **iOS 26.6.4**

---

## Используемые техники тестирования

Во время выполнения проекта применялись:

- ручное функциональное тестирование;
- проверка пользовательского интерфейса (UI);
- тестирование навигации;
- тестирование восстановления после изменения состояния сети;
- проверка отображения данных;
- проверка пользовательских сценариев.
