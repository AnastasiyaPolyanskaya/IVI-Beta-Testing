# Test Cases - IVI Profile Management & TV Interface Testing

В данном разделе представлены тест-кейсы, разработанные для проверки функциональности мобильного приложения IVI после обновления пользовательского интерфейса, навигации и внутренних компонентов приложения.

Тест-кейсы охватывают основные пользовательские сценарии и позволяют убедиться в корректной работе приложения после внесённых изменений.

---

## Цель

Проверить работоспособность обновлённого функционала, стабильность приложения и соответствие фактического поведения ожидаемым требованиям.

---

## Области тестирования

### 1. Работа профилей

Проверено:

- загрузка приложения после восстановления интернет-соединения;
- переключение между детским и взрослым профилями;
- отсутствие отображения контента 16+ в детском профиле.

---

### 2. Пользовательский интерфейс

Проверено:

- открытие раздела «Способы оплаты»;
- работа процесса оформления подписки;
- корректность переходов между экранами;
- отсутствие мерцаний, скачков и других визуальных дефектов интерфейса.

---

### 3. Карточки коллекций

Проверено:

- открытие карточек коллекций;
- корректное отображение изображений;
- работа скролла;
- переходы внутри карточек.

---

### 4. Телевизионные передачи

Проверено:

- отображение временных шильдов;
- корректность текста в зависимости от времени начала передачи;
- соответствие цветового оформления утверждённому дизайну.

---

## Структура тест-кейсов

Каждый тест-кейс содержит:

- ID тест-кейса;
- название тест-кейса;
- предусловия;
- шаги выполнения;
- ожидаемый результат;
- фактический результат;
- окружение;
- статус выполнения.

---

## Окружение

Тестирование проводилось на:

- **iPhone 14 Pro Max**
- **iOS 26.6.4**

---

## Результаты тестирования

В ходе тестирования были проверены:

- работа детского и взрослого профилей;
- восстановление работы приложения после появления сети;
- раздел «Способы оплаты»;
- оформление подписки;
- навигация между экранами;
- карточки коллекций;
- отображение временных шильдов телевизионных передач.

Все обнаруженные несоответствия оформлены в разделе **Bug Reports**.
