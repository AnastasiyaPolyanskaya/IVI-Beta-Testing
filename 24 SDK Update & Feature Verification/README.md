1. Проверка базового функционала (IOS‑19584)
Предусловия:

вход в аккаунт не выполнен;

открыт федеральный канал.

Что проверить:

воспроизведение видео;

смену качества (если доступно);

включение субтитров (если доступно).

Ожидаемый результат: всё работает корректно.

2. Проверка бесшовных переходов между экранами (IOS‑19355)
Где проверить:

Главный экран:

открытие карточки контента;

закрытие кнопкой «Назад» (карточка должна корректно вернуться на предыдущий экран);

закрытие свайпом вниз (должно работать плавно, без рывков);

закрытие свайпом от левого края (должно работать плавно);

отмена свайпа вниз (при возврате карточки в исходное положение она остаётся открытой, функционал не нарушается);

отмена свайпа от края (при возврате карточки в исходное положение она остаётся открытой, функционал не нарушается);

работа плеера на карточке (после закрытия карточки плеер должен корректно остановиться).

Главная: блок «Продолжить просмотр»:

все пункты из раздела «Главный экран».

Поиск: результаты live search:

все пункты из раздела «Главный экран».

Переход через контекстное меню / быстрые действия:

все пункты из раздела «Главный экран».

Таб «Моё»: избранное и «Продолжить просмотр»:

все пункты из раздела «Главный экран».

Каталог: жанровые страницы, страницы подборок / коллекций:

все пункты из раздела «Главный экран».

Карточка контента: переход в другую карточку из рекомендаций / аудио‑галереи:

корректность перехода между карточками;

отсутствие мерцаний, скачков, чёрных / белых кадров;

корректный возврат на предыдущий экран.

Ожидаемый результат: все переходы выполняются бесшовно, без визуальных артефактов и сбоев.

3. Проверка двойной галереи ПП на iPhone (IOS‑19641)
Предусловия:

устройство — iPhone любой модели;

в ПП более 5 единиц недосмотренного контента.

Шаги проверки:

Перейти на главную.

Проскроллить галерею ПП вправо.

Тапнуть по карточке из нижнего ряда.

Просмотреть / промотать контент до новой точки прогресса и вернуться на главную.

Проскроллить галерею в начало.

Что проверить:

одновременный скролл обоих рядов галереи;

отображение новых элементов в галерее;

открытие экрана плеера при тапе на карточку;

фокус на прежнем месте при возврате в галерею ПП;

отсутствие просмотренного контента на прежнем месте;

размещение контента с обновлённым прогрессом просмотра на первой позиции верхнего ряда.

Ожидаемый результат:

оба ряда галереи скроллятся одновременно;

отображаются новые элементы в галерее;

при тапе на карточку открывается экран плеера;

при возврате отображается галерея ПП с фокусом на прежнем месте;

просмотренный контент не отображается на прежнем месте;

контент с обновлённым прогрессом просмотра отображается на первой позиции верхнего ряда.
