# Bug Reports - IVI iOS Testing


В данном разделе представлены результаты ручного тестирования мобильного приложения **IVI**.

Отчёты составлены на основе выполненных тест-кейсов и содержат информацию о результатах проверки приглашения в подписку, вертикальных постеров, поведения приложения при смене сети, видеоплеера, режима разработчика, раздела «Книги» и работы детского профиля.

---

## Цель

Проверить работу функциональности мобильного приложения IVI на iOS, сравнить фактический результат с ожидаемым и зафиксировать обнаруженные отклонения или сценарии, недоступные для полноценного тестирования.

---

## Область тестирования

В ходе тестирования были проверены следующие тест-кейсы:

### 1. IOS-19680

Проверено:

- возможность отправки приглашения в подписку;
- переход по ссылке-приглашению;
- принятие приглашения;
- корректность завершения сценария.

Результат:

- в iOS-приложении отсутствует возможность пригласить пользователя в подписку;
- приглашение было отправлено через web-версию;
- при использовании приглашения из web-версии дальнейший сценарий работает корректно;
- приглашение успешно принимается.

Ограничение:

- полностью проверить сценарий средствами iOS-приложения невозможно из-за отсутствия функции отправки приглашения.

Статус:

- **BLOCKED**.

## Выявленные ограничения

### IOS-19680 — отсутствует возможность отправить приглашение из приложения

В iOS-приложении не обнаружена возможность пригласить пользователя в подписку.

Для продолжения тестирования приглашение было отправлено через web-версию IVI. После получения ссылки сценарий принятия приглашения в приложении работает корректно.

**Статус:** BLOCKED.

**Комментарий:**  
Требуется уточнение требований: должна ли возможность отправки приглашения присутствовать непосредственно в iOS-приложении. Если данная функциональность предусмотрена требованиями, результат может быть зарегистрирован как отдельный дефект.

---

### IOS-16968 — отсутствует возможность добавить детский аккаунт

В текущей версии приложения отсутствует возможность добавить детский аккаунт.

Из-за этого невозможно выполнить основную часть тестового сценария, включая проверку детской Главной, приглашения в подписку, перехода по ссылке на контент 18+ и переключения между детским и взрослым профилями.

**Статус:** BLOCKED.

**Комментарий:**  
Требуется уточнить доступность функции создания детского аккаунта для используемого аккаунта и тестового окружения. Если возможность создания детского аккаунта должна быть доступна, результат может быть зарегистрирован как дефект.
