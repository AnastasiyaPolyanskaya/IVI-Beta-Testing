# 32 - Subscription Invitation, Vertical Posters, Network Stability & Player

Практический проект по исследовательскому, функциональному и UI/UX-тестированию сервиса IVI.  
Ниже представлен чек-лист проверки свежих исправлений в iOS-приложении.

## Структура проверок

### Принятие приглашения в подписку

**Что проверить:**
1. Открыть приложение, авторизоваться
2. Получить приглашение в подписку (по ссылке)
3. Принять приглашение

**Ожидаемый результат IOS-19680:**  
Сценарий работает без ошибок, переход в подписку успешен.

---

### Отображение вертикальных постеров

**Что проверить:**
1. Открыть раздел с вертикальными постерами (Главная, Категории)
2. Проскроллить ленту
3. Открыть карточку контента из вертикального блока
4. Вернуться назад

**Ожидаемый результат IOS-20274:**  
Постеры отображаются ровно и корректно, без артефактов и дубликатов, переходы работают.

---

### Ошибки при смене сети / нестабильной сети

**Что проверить:**
1. Зайти на экран Поиск, ввести запрос
2. Переключить Wi-Fi на мобильный интернет и обратно (или включить/выключить авиарежим)
3. Перейти в плеер, смотреть контент при нестабильной сети
4. Проверить, что блоки в «Избранном» не перезагружаются при смене сети

**Ожидаемый результат IOS-20609:**  
Лишние сообщения об ошибках не появляются, попапы ошибок не возникают, когда экран скрыт.

---

### Буферизация видео в плеере

**Что проверить:**
1. Подключиться через Wi-Fi
2. Запустить фильм или сериал
3. Убедиться, что видео не буферизуется дольше 40 секунд
4. Воспроизведение → пауза → возобновление → выход

**Ожидаемый результат IOS-20571:**  
Плеер работает корректно: буферизация в норме, пауза и возобновление работают.

---

### Режим разработчика в профиле

**Что проверить:**
1. Авторизоваться в приложении
2. Открыть профиль
3. В приложении нажать на версию приложения 7 раз
4. Попробовать открыть Режим Разработчика

**Ожидаемый результат IOS-20706:**  
Режим Разработчика открывается без необходимости разлогиниваться.

---

### Название раздела с аудиокнигами

**Что проверить:**
1. Открыть нижнее меню приложения
2. Найти раздел с аудио-контентом

**Ожидаемый результат IOS-20141:**  
Название раздела — «Книги» (вместо «Аудио»).

---

### Главная в детском и взрослом аккаунте

**Что проверить:**
1. Создать детский аккаунт, перейти на главную — проверить отображение
2. Удалить детский аккаунт со второго устройства, на первом свернуть/развернуть приложение
3. Принять приглашение в подписку из детского аккаунта
4. Перейти по ссылке контента 18+ из детского аккаунта, авторизоваться во взрослого
5. Переключиться на взрослый профиль через «Кто смотрит?»

**Ожидаемый результат IOS-16968:**  
В детском аккаунте — главная с бесконечным скроллом, во взрослом — новая главная с бесконечным скроллом, переключения между профилями работают корректно.
