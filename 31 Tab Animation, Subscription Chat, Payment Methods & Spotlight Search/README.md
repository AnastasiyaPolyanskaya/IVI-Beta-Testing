# 31 - Tab Animation, Subscription Chat, Payment Methods & Spotlight Search

Практический проект по исследовательскому, функциональному и UI/UX-тестированию сервиса IVI.  
Ниже представлен чек-лист проверки свежих исправлений в iOS-приложении.

## Структура проверок

### Анимация переключения вкладок

**Что проверить:**
1. Понажимать поочерёдно на все вкладки внизу экрана (Главная, Поиск, ТВ, Мой Иви) по несколько раз, быстро и медленно

**Ожидаемый результат IOS-20546:**  
Анимация переключения проигрывается плавно, без зависаний, дёрганий и артефактов; подсветка активной вкладки всегда соответствует выбранной.

---

### Чат покупки подписки

**Предусловие:**  
- Авторизованный пользователь без активной подписки

**Что проверить:**
1. Открыть покупку подписки и пройти чат покупки до конца  
2. Закрыть итоговый экран с результатом покупки

**Ожидаемый результат IOS-20471:**  
Чат закрывается корректно, приложение не зависает; после закрытия итоговый экран не появляется повторно сам по себе.

---

### Экран выбора способа оплаты

**Что проверить:**
1. Открыть покупку подписки до шага выбора способа оплаты  
2. Просмотреть все доступные способы, выбрать любой, вернуться назад и выбрать другой

**Ожидаемый результат IOS-15594:**  
Экран выбора способа оплаты открывается, все способы отображаются корректно, выбор и смена способа работают без ошибок.

---

### Поиск контента через системный поиск (Spotlight)

**Предусловие:**  
- В настройках iOS поиск по приложению Иви включён

**Что проверить:**
1. На домашнем экране свайпнуть вниз, ввести название фильма или сериала (например, «Форсаж» или «Слово пацана»)  
2. Найти в выдаче результат от Иви и нажать на него

**Ожидаемый результат IOS-17323:**  
Контент Иви отображается в результатах Spotlight, переход в приложение происходит корректно на нужную страницу.

## Цель
Демонстрация навыков ручного тестирования:
- составление тест-кейсов;
- оформление баг-репортов;
- проверка исправлений;
- тестирование iOS.
