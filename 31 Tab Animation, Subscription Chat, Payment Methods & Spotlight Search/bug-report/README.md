# Bug Reports - IVI iOS Testing

В данном разделе представлены результаты ручного тестирования мобильного приложения IVI.

Отчёты составлены на основе выполненных тест-кейсов и содержат информацию о результатах проверки способов оплаты, управления подпиской, системного поиска и других пользовательских сценариев.

---

## Цель

Проверить работу функциональности мобильного приложения IVI на iOS, сравнить фактический результат с ожидаемым и зафиксировать обнаруженные отклонения.

---

## Область тестирования

В ходе тестирования были проверены следующие тест-кейсы:

### 1. IOS-20546

Проверено:

- выполнение сценария согласно тест-кейсу;
- соответствие фактического результата ожидаемому.

Результат:

- фактический результат соответствует ожидаемому;
- дефекты не обнаружены.

---

### 2. IOS-20471

Проверено:

- доступность способов оплаты подписок;
- возможность выбора различных способов оплаты.

Результат:

- покупка подписки не выполнялась;
- оплата всех подписок доступна через СБП, в том числе через «Другие банки»;
- оплата всех подписок доступна новой банковской картой;
- для всех подписок, кроме «Иви + Amediateka», дополнительно доступна оплата через App Store.

---

### 3. IOS-15594

Проверено:

- отображение доступных способов оплаты;
- переход на экран выбранного способа оплаты;
- возврат с экрана выбранного способа оплаты.

Результат:

- основной результат соответствует ожидаемому;
- при возврате с экрана выбранного способа оплаты пользователь попадает на экран управления подпиской вместо экрана выбора способов оплаты.

Выявленное отклонение:

- возврат осуществляется не на экран выбора способов оплаты, а на экран управления подпиской.

---

### 4. IOS-17323

Проверено:

- отображение контента IVI в результатах системного поиска;
- настройки отображения приложения IVI и его контента в результатах поиска.

Результат:

- фактический результат не соответствует ожидаемому;
- контент IVI отсутствует в результатах поиска;
- в настройках устройства разрешён показ приложения IVI и его контента в результатах поиска.

Выявленный дефект:

- контент IVI не отображается в результатах системного поиска при включённых соответствующих разрешениях.

## Итоги тестирования

В ходе проверки были получены следующие результаты:

- **IOS-20546** — результат соответствует ожидаемому, дефекты не обнаружены;
- **IOS-20471** — доступны способы оплаты через СБП и новую банковскую карту. Для всех подписок, кроме «Иви + Amediateka», также доступна оплата через App Store. Покупка подписки не выполнялась;
- **IOS-15594** — основной результат соответствует ожидаемому, однако обнаружено отклонение при возврате с экрана выбранного способа оплаты: происходит переход на экран управления подпиской вместо экрана выбора способов оплаты;
- **IOS-17323** — результат не соответствует ожидаемому: контент IVI отсутствует в результатах системного поиска, несмотря на включённое разрешение на его отображение в настройках устройства.

---

## Выявленные отклонения

### IOS-15594 — некорректный экран возврата

При возврате с экрана выбранного способа оплаты пользователь попадает на экран управления подпиской вместо экрана выбора способов оплаты.

**Предполагаемая серьёзность:** Minor.

---

### IOS-17323 — контент IVI отсутствует в системном поиске

Контент приложения IVI не отображается в результатах системного поиска, несмотря на то, что в настройках устройства разрешено отображение приложения и его контента в результатах поиска.

**Предполагаемая серьёзность:** Minor.

---

## Вывод

В ходе тестирования были проверены четыре тест-кейса мобильного приложения IVI.

Тест-кейс **IOS-20546** пройден успешно — фактический результат соответствует ожидаемому.

В рамках **IOS-20471** проверена доступность способов оплаты. Все подписки можно оплатить через СБП или новой банковской картой. Для всех подписок, кроме «Иви + Amediateka», также доступна оплата через App Store. Фактическая покупка подписки не выполнялась.

В **IOS-15594** основной сценарий соответствует ожидаемому, однако обнаружено отклонение в навигации при возврате с экрана выбранного способа оплаты.

Тест-кейс **IOS-17323** не соответствует ожидаемому результату: контент IVI не появляется в системном поиске при включённых разрешениях на его отображение.
