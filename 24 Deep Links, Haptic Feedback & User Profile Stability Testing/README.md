# 24 - Deep Links, Haptic Feedback & User Profile Stability Testing

Практический проект по ручному тестированию мобильного приложения IVI.

В рамках проекта проведено тестирование пользовательских сценариев, связанных с диплинками, системными хаптиками (вибрациями), авторизацией, детскими аккаунтами и работой блока «Продолжить просмотр».

---

## Цель проекта

Проверить корректность работы новых диплинков, стабильность приложения после авторизации, работу системных вибраций и корректность обновления пользовательских данных.

---

## Объект тестирования

Мобильное приложение IVI

- Платформа: iOS  
- Тип тестирования: Manual QA  

---

## Области тестирования

### 1. Deep Links (диплинки)

Проверено:

- открытие раздела:
  - «Чеки»;
  - «Способы оплаты»;
  - «Мои устройства»;

- корректность перехода по диплинкам;
- соответствие открытого раздела диплинку.

Ожидаемый результат:
- при переходе по диплинку открывается соответствующий раздел приложения.

---

### 2. Хаптики (вибрации)

Проверено:

- работа вибраций при переключении тоглов;
- работа вибраций на экране ввода кода;
- работа вибраций при изменении громкости плеера;
- корректность системного отклика.

Ожидаемый результат:
- хаптики работают корректно.

---

### 3. Поддержка iOS

Проверено:

- работа приложения на поддерживаемых версиях iOS;
- стабильность запуска и использования приложения.

Ожидаемый результат:
- приложение работает корректно.

---

### 4. Авторизация и детский аккаунт

Проверено:

- переход по диплинку на контент 18+;
- работа попапа:
  «Недоступно в детском аккаунте»;
- авторизация в другой аккаунт;
- открытие карточки контента после авторизации;
- отсутствие крашей.

Ожидаемый результат:
- пользователь успешно авторизуется;
- открывается карточка контента 18+;
- приложение не крашится.

---

### 5. Блок «Продолжить просмотр»

Проверено:

- обновление ленты;
- удаление контента из блока ПП;
- работа приложения после смены сети;
- корректность обновления данных.

Ожидаемый результат:
- контент корректно удаляется из блока «Продолжить просмотр».

---

## Особенности тестирования

Тестирование включало:

- проверку deep links;
- тестирование пользовательских сценариев авторизации;
- проверку системных вибраций;
- тестирование обновления контента;
- проверку стабильности приложения.

---

## Результаты тестирования

В ходе тестирования проверено:

- корректное открытие разделов по диплинкам;
- стабильная работа авторизации;
- работа системных хаптиков;
- корректное обновление пользовательских данных;
- отсутствие критических сбоев.

Выявленные дефекты фиксируются в разделе bug-reports.
