# Test Cases - Offline Mode & Authorization UI Testing

В данном разделе представлены тест-кейсы, разработанные для проверки работы офлайн-режима, экранов авторизации, локализации интерфейса и настроек уведомлений в мобильном приложении IVI.

Тест-кейсы позволяют оценить корректность работы приложения после обновления пользовательского интерфейса и внутренних доработок системы.

---

## Цель

Проверить стабильность работы приложения, корректность отображения новых экранов и соответствие интерфейса требованиям после внесённых изменений.

---

## Области тестирования

### 1. Локализация экрана авторизации

Проверено:

- отображение юридических документов на узбекском языке;
- корректность переноса текста;
- соответствие отображения утверждённому макету.

---

### 2. Обновление приложения

Проверено:

- обновление приложения со старой версии;
- запуск приложения после обновления;
- работа приложения после восстановления интернет-соединения;
- корректная загрузка главного экрана и других разделов.

---

### 3. Экран загрузок в офлайн-режиме

Проверено:

- отображение экрана при отсутствии загруженного контента;
- отображение экрана при наличии скачанного контента;
- соответствие экранов дизайн-макетам.

---

### 4. Экран-заглушка в офлайн-режиме

Проверено:

- отображение заглушки без скачанного контента;
- отображение заглушки при наличии скачанного контента;
- корректность отображения элементов интерфейса.

---

### 5. Настройки уведомлений

Проверено:

- отображение раздела настроек уведомлений;
- скрытие недоступных настроек при отсутствии привязанного номера телефона;
- скрытие недоступных настроек при отсутствии привязанной электронной почты.

---

### 6. Экран ввода кода

Проверено:

- отображение экрана ввода кода подтверждения;
- отображение экрана установки PIN-кода;
- отображение экрана изменения PIN-кода;
- соответствие интерфейса актуальному дизайну.

---

## Структура тест-кейсов

Каждый тест-кейс содержит:

- ID тест-кейса;
- название тест-кейса;
- предусловия;
- шаги выполнения;
- ожидаемый результат;
- фактический результат;
- окружение;
- статус выполнения.

---

## Окружение

Тестирование проводилось на:

- iPhone 14 Pro Max;
- iOS 26.6.4.

Дополнительно для проверки локализации использовались:

- язык устройства — O'zbekcha;
- язык приложения IVI — O'zbekcha;
- IP-адрес региона Узбекистан.

---

## Результаты тестирования

В ходе тестирования были проверены:

- экран авторизации;
- локализация юридических документов;
- обновление приложения;
- офлайн-режим;
- экран загрузок;
- экран-заглушка;
- настройки уведомлений;
- экран ввода кода.

Все выявленные дефекты фиксируются в разделе **bug-reports**.
