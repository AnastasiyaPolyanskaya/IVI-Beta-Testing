# Bug Reports - IVI Offline Mode & Authorization UI Testing

В данном разделе представлены баг-репорты, выявленные в ходе ручного тестирования мобильного приложения IVI.

Отчёты составлены на основе выполненных тест-кейсов и содержат информацию о дефектах, обнаруженных при проверке экранов авторизации, офлайн-режима, локализации интерфейса и пользовательских настроек.

---

## Цель

Зафиксировать обнаруженные дефекты, предоставить подробные шаги воспроизведения и передать информацию разработчикам для последующего исправления.

---

## Область дефектов

В ходе тестирования были проверены следующие функциональные области:

### 1. Локализация

Проверено:

- перенос текста юридических документов на экране авторизации при узбекской локализации.

Результат:

- сценарий не удалось проверить из-за отсутствия необходимых условий тестирования.

---

### 2. Обновление приложения

Проверено:

- работа приложения после обновления со старой версии;
- загрузка экранов после восстановления интернет-соединения.

Результат:

- дефекты не обнаружены.

---

### 3. Оффлайн-режим

Проверено:

- экран загрузок без сети;
- экран-заглушка без подключения к интернету.

Результат:

- дефекты не обнаружены.

---

### 4. Настройки уведомлений

Проверено:

- скрытие недоступных пунктов настроек уведомлений при отсутствии привязанных данных пользователя.

Результат:

- дефекты не обнаружены.

---

### 5. Экран ввода кода

Проверено:

- экран ввода PIN-кода;
- экран ввода кода подтверждения.

Выявленный дефект:

- экран ввода кода и отображаемые надписи отличаются от ожидаемого дизайна.

---

## Структура баг-репорта

Каждый баг-репорт содержит:

- ID;
- название дефекта;
- окружение;
- предусловия;
- шаги воспроизведения;
- ожидаемый результат;
- фактический результат;
- серьёзность (Severity);
- приоритет (Priority);
- комментарий.

---

## Окружение

Тестирование проводилось на:

- iPhone 14 Pro Max;
- iOS 26.6.4.

---

## Серьёзность дефектов

В проекте использовалась следующая классификация:

- **Critical** — приложение неработоспособно или происходит потеря данных;
- **Major** — нарушен основной функционал;
- **Minor** — частично нарушена работа функции или интерфейса;
- **Trivial** — визуальные или малозначительные дефекты.

---

## Итоги тестирования

В ходе проверки большинство пользовательских сценариев были успешно пройдены без замечаний.

Выявлен один дефект, связанный с отображением обновлённого экрана ввода кода, который не соответствует ожидаемому дизайну. Проверка сценария локализации юридических документов не была выполнена из-за отсутствия необходимых условий тестирования.

---

## Вывод

Тестирование подтвердило стабильную работу основных функций приложения после обновления. Большинство сценариев соответствует ожидаемому результату, однако экран ввода кода требует доработки для полного соответствия утверждённому макету интерфейса.
