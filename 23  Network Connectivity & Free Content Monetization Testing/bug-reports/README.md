# Bug Reports - IVI (Network Connectivity & Free Content Monetization)

В данном разделе представлены баг-репорты, выявленные в ходе тестирования мобильного приложения IVI.

Баг-репорты отражают дефекты, связанные с работой приложения при различных типах сети, отсутствием интернет-соединения и воспроизведением бесплатного контента пользователями без подписки.

---

## Цель

Зафиксировать найденные дефекты, описать условия их воспроизведения и предоставить информацию для их исправления.

---

## Область дефектов

В ходе тестирования были выявлены дефекты в следующих функциональных областях:

### 1. Работа сети

- некорректное отображение элементов при отсутствии интернета;
- возможные проблемы запуска приложения;
- ошибки при восстановлении соединения.

---

### 2. Бесплатный контент и монетизация

- отсутствие кнопки:
  - «Смотреть по подписке»;
  - «Продолжить с рекламой»;
- некорректная работа блока «Продолжить просмотр»;
- нарушение пользовательского сценария просмотра бесплатного контента.

---

### 3. UI и отображение

- некорректное отображение элементов интерфейса;
- отсутствие ожидаемых кнопок;
- несоответствие ожидаемому поведению приложения.

---

## Структура баг-репорта

Каждый баг-репорт содержит:

- ID  
- Название  
- Окружение  
- Предусловия  
- Шаги воспроизведения  
- Ожидаемый результат  
- Фактический результат  
- Серьёзность (Severity)  
- Приоритет (Priority)  
- Комментарий  

---

## Окружение

Тестирование проводилось на:

- iPhone 14 Pro Max  
- iOS 26.3.1  

---

## Серьёзность дефектов

В проекте использовалась следующая градация:

- Critical — блокирует работу приложения  
- Major — влияет на ключевой функционал  
- Minor — незначительные дефекты  
- Trivial — визуальные недочёты  

---

## Вывод

В ходе тестирования были выявлены дефекты, влияющие на пользовательские сценарии запуска бесплатного контента и отображение элементов монетизации.

Особое внимание требуется уделить:
- корректной работе бесплатного контента;
- отображению кнопок монетизации;
- стабильности приложения при различных сетевых условиях.
