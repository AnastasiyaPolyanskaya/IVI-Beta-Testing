# 23 - Network Connectivity & Free Content Monetization Testing

Практический проект по ручному тестированию мобильного приложения IVI.

В рамках проекта проведено тестирование пользовательских сценариев, связанных с запуском приложения при различных типах сети, отсутствием интернета и воспроизведением бесплатного контента пользователем без подписки.

---

## Цель проекта

Проверить стабильность запуска приложения в различных сетевых условиях, а также корректность работы монетизации бесплатного контента.

---

## Объект тестирования

Мобильное приложение IVI

- Платформа: iOS  
- Устройство: iPhone 14 Pro Max  
- Версия iOS: 26.3.1  
- Тип тестирования: Manual QA  

---

## Области тестирования

### 1. Работа приложения с сетью

Проверено:

- запуск приложения через Wi-Fi:
  - авторизованным пользователем;
  - неавторизованным пользователем;

- запуск приложения через мобильный интернет:
  - авторизованным пользователем;
  - неавторизованным пользователем;

- работа приложения при отсутствии сети.

Ожидаемый результат:
- приложение корректно запускается;
- отображается сообщение об отсутствии интернета при отключенной сети.

---

### 2. Работа приложения без сети

Проверено:

- отображение сообщения:
  «Нет соединения с интернетом, повтори попытку или перейди в раздел загрузки»;
- корректность поведения приложения при отсутствии интернета.

Ожидаемый результат:
- сообщение отображается корректно;
- приложение не крашится.

---

### 3. Бесплатный контент и монетизация

Проверено:

- запуск бесплатного контента пользователем без подписки;
- отображение кнопки:
  - «Смотреть по подписке»;
  - «Продолжить с рекламой»;
- корректность работы блока «Продолжить просмотр».

Ожидаемый результат:
- отображаются обе кнопки монетизации;
- пользователь может продолжить просмотр контента с рекламой.

---

## Особенности тестирования

Тестирование включало:

- проверку разных типов сети;
- тестирование авторизованных и неавторизованных пользователей;
- проверку работы приложения без интернета;
- проверку пользовательских сценариев монетизации;
- тестирование UI и логики воспроизведения.

---

## Результаты тестирования

В ходе тестирования проверено:

- стабильное поведение приложения при разных типах подключения;
- корректность отображения системных сообщений;
- работа бесплатного контента;
- отображение элементов монетизации.

Выявленные дефекты фиксируются в разделе bug-reports.
