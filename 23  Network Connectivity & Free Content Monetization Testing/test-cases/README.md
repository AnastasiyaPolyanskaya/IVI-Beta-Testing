# Test Cases - IVI (Network Connectivity & Free Content Monetization)

В данном разделе представлены тест-кейсы для проверки работы мобильного приложения IVI в различных сетевых условиях, а также проверки сценариев воспроизведения бесплатного контента пользователями без подписки.

Тест-кейсы охватывают пользовательские сценарии, связанные с запуском приложения, отсутствием интернет-соединения и отображением элементов монетизации.

---

## Цель тестирования

Проверить стабильность работы приложения при разных типах подключения к сети и корректность работы бесплатного контента.

---

## Область покрытия

### 1. Работа приложения с сетью

Проверено:

- запуск приложения через Wi-Fi:
  - авторизованным пользователем;
  - неавторизованным пользователем;

- запуск приложения через мобильный интернет:
  - авторизованным пользователем;
  - неавторизованным пользователем;

- работа приложения при отсутствии интернет-соединения.

---

### 2. Работа без сети

Проверено:

- отображение сообщения:
  «Нет соединения с интернетом, повтори попытку или перейди в раздел загрузки»;
- корректность работы приложения при отключённой сети;
- отсутствие крашей.

---

### 3. Бесплатный контент

Проверено:

- запуск бесплатного контента пользователем без подписки;
- отображение кнопки:
  - «Смотреть по подписке»;
  - «Продолжить с рекламой»;
- работа блока «Продолжить просмотр»;
- корректность отображения элементов монетизации.

---

## Структура тест-кейсов

Каждый тест-кейс содержит:

- ID  
- Название  
- Предусловия  
- Шаги выполнения  
- Ожидаемый результат (ОР)  
- Фактический результат (ФР)  
- Окружение  
- Результат  

---

## Окружение

Тестирование проводилось на:

- iPhone 14 Pro Max  
- iOS 26.3.1  

---

## Особенности тестирования

- проверка различных типов подключения;
- тестирование авторизованных и неавторизованных пользователей;
- проверка поведения приложения без сети;
- проверка пользовательских сценариев монетизации;
- анализ UI и стабильности приложения.

---

## Результаты

В ходе выполнения тест-кейсов проверено:

- стабильное открытие приложения;
- корректное отображение системных сообщений;
- работа бесплатного контента;
- отображение кнопок монетизации.

Выявленные дефекты фиксируются в разделе bug-reports.

---

## Примечание

Тест-кейсы направлены на проверку устойчивости приложения при различных сетевых условиях и корректной работы сценариев просмотра бесплатного контента.
