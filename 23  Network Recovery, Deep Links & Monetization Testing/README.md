# 23 - Network Recovery, Deep Links & Monetization Testing

Практический проект по ручному тестированию мобильного приложения IVI.

В рамках проекта проведено тестирование функциональности, связанной с запуском приложения, работой сети, диплинками, монетизацией бесплатного контента и обновлением интерфейса профиля.

---

## Цель проекта

Проверить стабильность и корректность работы приложения при различных сетевых условиях, а также убедиться в корректной работе новых пользовательских сценариев.

---

## Объект тестирования

Мобильное приложение IVI

- Платформа: iOS  
- Тип тестирования: Manual QA  

---

## Области тестирования

### 1. Запуск приложения

Проверено:

- запуск приложения:
  - через мобильный интернет;
  - через Wi-Fi;
  - без сети;
  - при переключении сети;
  - в авторизованном и неавторизованном состоянии;
  - с подпиской и без подписки.

Ожидаемый результат:
- приложение успешно запускается во всех сценариях.

---

### 2. Deep Links (диплинки)

Проверено:

- открытие новых диплинков;
- корректность перехода в раздел поддержки;
- работа навигации внутри приложения.

Ожидаемый результат:
- приложение открывается в разделе поддержки.

---

### 3. Бесплатный контент и монетизация

Проверено:

- запуск бесплатного контента из блока «Продолжить просмотр» пользователем без подписки;
- отображение монетизационных кнопок;
- запуск рекламы;
- корректность открытия плеера.

Ожидаемый результат:
- отображаются кнопки:
  - «Смотреть по подписке»
  - «Продолжить с рекламой»;
- запускается реклама;
- начинается воспроизведение контента.

---

### 4. Восстановление сети

Проверено:

- отображение блоков:
  - Просмотры
  - Покупки
  - Буду смотреть
- восстановление данных после возврата интернет-соединения;
- работа приложения после режима полета.

Ожидаемый результат:
- контент отображается корректно после восстановления сети.

---

### 5. UI профиля

Проверено:

- отображение кнопки поддержки;
- корректность расположения кнопки на экране профиля;
- отображение рядом с кнопкой чеков.

Ожидаемый результат:
- кнопка поддержки отображается корректно.

---

## Особенности тестирования

Тестирование включало:

- проверку нестандартных сетевых сценариев;
- тестирование работы без интернета;
- проверку монетизации;
- проверку пользовательских сценариев;
- анализ UI и навигации.

---

## Результаты тестирования

В ходе тестирования проверено:

- стабильное поведение приложения;
- корректная работа диплинков;
- восстановление данных после сети;
- корректная работа монетизации;
- стабильность интерфейса профиля.

Выявленные дефекты фиксируются в разделе bug-reports.
