# 22 - Stability, Deep Links & Playback Testing

Практический проект по ручному тестированию мобильного приложения IVI.

В рамках проекта проведено тестирование исправлений, связанных со стабильностью приложения, запуском контента, диплинками, мини-плеером и восстановлением данных после потери сети.

---

## Цель проекта

Проверить корректность работы приложения после внесённых исправлений и убедиться в отсутствии критических ошибок в пользовательских сценариях.

---

## Объект тестирования

Мобильное приложение IVI.

- Платформа: iOS  
- Тип тестирования: Manual QA  

---

## Области тестирования

### 1. Скачивание контента

Проверено:
- скачивание большого объема контента;
- поведение приложения при полностью заполненной памяти устройства;
- попытка скачать дополнительный контент после переполнения памяти;
- отсутствие крашей.

Ожидаемый результат:
- приложение не завершается аварийно;
- пользователь получает корректное поведение системы.

---

### 2. Ограничение авторизованных устройств

Проверено:
- отображение экрана ограничения устройств;
- отключение одного устройства;
- отключение нескольких устройств;
- закрытие экрана ограничений;
- стабильность приложения.

Ожидаемый результат:
- краши отсутствуют;
- функционал работает корректно.

---

### 3. Мини-плеер и трансляции

Проверено:пппп
- поведение мини-плеера при открытии онлайн-трансляции;
- корректность закрытия mini-player.

Ожидаемый результат:
- мини-плеер корректно закрывается при открытии трансляции.

---

### 4. Скорость запуска приложения

Проверено:
- запуск приложения:
  - с мобильного интернета;
  - через Wi-Fi;
  - без сети;
  - при переключении сети;
  - в авторизованном и неавторизованном состоянии;
  - с подпиской и без подписки.

Ожидаемый результат:
- приложение успешно запускается во всех сценариях.

---

### 5. Deep Links (диплинки)

Проверено:
- открытие новых диплинков;
- переход в нужный раздел приложения.

Ожидаемый результат:
- приложение открывается в разделе поддержки.

---

### 6. Воспроизведение бесплатного контента

Проверено:
- запуск бесплатного контента из блока «Продолжить просмотр» пользователем без подписки;
- отображение монетизации;
- воспроизведение рекламы.

Ожидаемый результат:
- отображаются 2 кнопки:
  - «Смотреть по подписке»
  - «Продолжить с рекламой»
- запускается реклама и начинается воспроизведение.

---

### 7. Восстановление данных после отсутствия сети

Проверено:
- отображение блоков:
  - Просмотры
  - Покупки
  - Буду смотреть
- восстановление данных после возврата сети.

Ожидаемый результат:
- контент отображается корректно после восстановления соединения.

---

### 8. UI профиля

Проверено:
- отображение кнопки поддержки на экране профиля;
- расположение рядом с кнопкой чеков.

Ожидаемый результат:
- кнопка поддержки отображается корректно.

---

## Особенности тестирования

Тестирование включало:

- стресс-сценарии;
- работу без сети;
- восстановление соединения;
- тестирование авторизации;
- проверку UI;
- проверку воспроизведения контента;
- проверку диплинков.

---

## Результаты тестирования

В ходе тестирования проверено:

- стабильное поведение приложения;
- отсутствие крашей;
- корректная работа воспроизведения;
- корректность UI и навигации.

Выявленные дефекты фиксируются в разделе bug-reports.
