# Test Cases - IVI (Stability, Deep Links & Playback)

В данном разделе представлены тест-кейсы для проверки стабильности мобильного приложения IVI после внесённых изменений и исправлений.

Тест-кейсы охватывают пользовательские сценарии, связанные со скачиванием контента, воспроизведением, работой сети, диплинками и интерфейсом приложения.

---

## Цель тестирования

Проверить корректность работы функционала приложения и убедиться в отсутствии критических ошибок и крашей.

---

## Область покрытия

### 1. Скачивание контента

Проверено:

- скачивание большого объема контента;
- поведение приложения при полностью заполненной памяти устройства;
- попытка скачать дополнительный контент;
- стабильность приложения при скачивании.

---

### 2. Ограничение авторизованных устройств

Проверено:

- отображение экрана ограничения устройств;
- отключение одного устройства;
- отключение нескольких устройств;
- закрытие экрана ограничения;
- отсутствие крашей.

---

### 3. Мини-плеер

Проверено:

- закрытие мини-плеера при открытии онлайн-трансляции;
- корректность поведения Picture in Picture.

---

### 4. Запуск приложения

Проверено:

- запуск приложения:
  - через мобильную сеть;
  - через Wi-Fi;
  - без сети;
  - при переключении сети;
  - в авторизованном и неавторизованном состоянии;
  - с подпиской и без подписки.

---

### 5. Deep Links

Проверено:

- открытие новых диплинков;
- переход в раздел поддержки;
- корректность навигации.

---

### 6. Бесплатный контент

Проверено:

- запуск бесплатного контента из блока «Продолжить просмотр»;
- отображение кнопок монетизации;
- запуск рекламы;
- корректность воспроизведения.

---

### 7. Работа без сети

Проверено:

- восстановление контента после возврата сети;
- отображение блоков:
  - Просмотры
  - Покупки
  - Буду смотреть

---

### 8. UI профиля

Проверено:

- отображение кнопки поддержки;
- корректность расположения элемента в профиле.

---

## Структура тест-кейсов

Каждый тест-кейс содержит:

- ID  
- Название  
- Предусловия  
- Шаги выполнения  
- Ожидаемый результат (ОР)  
- Фактический результат (ФР)  
- Окружение  
- Результат  

---

## Окружение

Тестирование проводилось на:

- iPhone 14 Pro Max  
- iOS 26.6.4  

---

## Особенности тестирования

- стресс-тестирование;
- проверка нестандартных сценариев;
- тестирование при отсутствии сети;
- проверка пользовательских сценариев;
- тестирование UI и навигации.

---

## Результаты

В ходе выполнения тест-кейсов проверено:

- отсутствие крашей;
- стабильность приложения;
- корректность воспроизведения контента;
- работа диплинков и UI.

Выявленные дефекты фиксируются в разделе bug-reports.

---

## Примечание

Тест-кейсы направлены на проверку устойчивости приложения и корректной работы ключевых пользовательских сценариев после внесённых изменений.
