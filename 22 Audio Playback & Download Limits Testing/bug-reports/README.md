# Bug Reports
В данной папке представлены баг‑репорты, выявленные в процессе тестирования мобильного приложения IVI для платформы iOS.

Тестирование проводилось в рамках проверки стабильности работы приложения при нехватке памяти, корректности системных сообщений и функциональности аудиоплеера.

Цель баг‑репортов
Зафиксировать обнаруженные дефекты;

Описать фактическое поведение приложения;

Сравнить ожидаемый и фактический результат;

Передать информацию команде разработки для исправления.

Обнаруженные дефекты
В ходе тестирования были выявлены следующие проблемы:

1. Загрузка контента при нехватке памяти
приложение может аварийно завершать работу при попытке загрузить контент при отсутствии свободной памяти;

некорректное отображение системных сообщений о нехватке памяти.

2. Функциональность аудиоплеера
отсутствует кнопка Picture‑in‑Picture (PiP) при прослушивании аудиоконтента;

отсутствует кнопка трансляции в интерфейсе аудиоплеера.

Баг #ив22
ID дефекта: BUG‑ив22.3
Название: Отсутствие кнопки Picture‑in‑Picture при прослушивании серии аудиосериала
Окружение: iPhone 14 Pro Max, iOS 26.6.4, приложение IVI
Серьёзность: Значительная
Приоритет: Средний

Предусловия:
Пользователь зарегистрирован.
Нажать кнопку «Аудио».
Шаги воспроизведения:
В поиске набрать «эхолов».
Нажать на карточку контента.
Запустить воспроизведение аудиосериала.

Проверить наличие кнопки Picture‑in‑Picture в интерфейсе плеера.

Ожидаемый результат: Появляется кнопка Picture‑in‑Picture, позволяющая свернуть аудио в мини‑окно.
Фактический результат: Кнопки Picture‑in‑Picture нет. Функция недоступна.
Скриншоты: bug_003_pip_missing.png
Комментарий: Отсутствие кнопки PiP ограничивает возможности многозадачности для пользователя.
