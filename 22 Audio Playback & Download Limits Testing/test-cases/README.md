# Test Cases - IVI (Audio Playback & Download Limits)

В данном разделе представлены тест-кейсы для проверки функциональности мобильного приложения IVI.

Тест-кейсы охватывают сценарии скачивания контента, обработку ограничений памяти устройства и работу аудио-контента.

---

## Цель тестирования

Проверить стабильность приложения при скачивании контента, корректность обработки нехватки памяти и работу элементов аудио-плеера.

---

## Область покрытия

### 1. Скачивание контента

Проверено:

- скачивание нескольких сезонов контента;
- поведение приложения при переполненной памяти устройства;
- попытка скачать дополнительный контент;
- отсутствие крашей при загрузке.

---

### 2. Ограничение памяти устройства

Проверено:

- отображение системного сообщения при отсутствии памяти;
- корректность текста уведомления;
- стабильность приложения при ограниченных ресурсах устройства.

---

### 3. Аудио-плеер

Проверено:

- отображение кнопки Picture in Picture;
- отображение кнопки трансляции;
- корректность отображения элементов интерфейса;
- работа карточки аудиоконтента.

---

## Структура тест-кейсов

Каждый тест-кейс содержит:

- ID  
- Название  
- Предусловия  
- Шаги выполнения  
- Ожидаемый результат (ОР)  
- Фактический результат (ФР)  
- Окружение  
- Результат  

---

## Окружение

Тестирование проводилось на:

- iPhone 14 Pro Max  
- iOS 26.6.4  

---

## Особенности тестирования

- стресс-тестирование;
- проверка работы при ограниченной памяти устройства;
- тестирование пользовательских сценариев;
- проверка UI и функциональности аудио-плеера.

---

## Результаты

В ходе выполнения тест-кейсов проверено:

- отсутствие крашей при нехватке памяти;
- корректное отображение уведомлений;
- стабильность работы скачивания;
- корректность отображения элементов аудио-раздела.

Выявленные дефекты фиксируются в разделе bug-reports.

---

## Примечание

Тест-кейсы направлены на проверку устойчивости приложения, корректной обработки ограничений памяти и работы нового функционала аудио-контента.
